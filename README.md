## Utilisation

Ces notes sont concues pour **Obsidian** (PKM — Personal Knowledge Management). Le fichier `doc/MOC — Systemes d'exploitation.md` sert de carte de contenu principale.

Pour les utiliser :
1. Cloner le depot
2. Ouvrir le dossier `doc/` comme vault Obsidian
3. Naviguer via le MOC (Map of Content)
